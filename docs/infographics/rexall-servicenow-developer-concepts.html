4. Platform Upgrade & Regression Testing Workflow

stateDiagram-v2
    [*] --> Clone: Clone Prod → Sub-Prod
    Clone --> Upgrade: Apply patch / upgrade
    Upgrade --> Regression: Run regression suite
    Regression --> Pass: All tests green
    Regression --> Fail: Triage & fix
    Fail --> Regression
    Pass --> Promote: Merge Update Sets → Prod
    Promote --> Smoke: Post-prod smoke test
    Smoke --> [*]
    
    note right of Regression
      - ITSM workflows
      - HRSD onboarding
      - Integration endpoints
      - Custom UI policies
      - ACL regression
    end note

Regression checklist (retail context): Catalog item submission → approval → task creation; Employee onboarding via HRSD; UKG/Boomi inbound sync; Service Portal widgets; Role-based access for pharmacy vs corporate users.
