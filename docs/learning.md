# Official Learning Portal

The primary authoritative sources for ServiceNow training are the Now Learning portal and the official Product Documentation. Avoid relying solely on third-party guides for certification preparation.

## 🎓 Now Learning (Structured Training)
The **Now Learning** portal is the only official source for structured training, certification paths, and badges.

- **Portal Link:** [Now Learning](https://nowlearning.servicenow.com/)
- **How to use:** 
    1. Sign in with your ServiceNow ID.
    2. Search for the specific module (e.g., "HR Service Delivery" or "ITSM").
    3. Filter by "Learning Path" to find end-to-end certification journeys.

## 📚 Product Documentation (The Source of Truth)
The **Product Documentation** is the definitive reference for every table, field, and OOB behavior across all releases.

- **Documentation Portal:** [ServiceNow Docs](https://docs.servicenow.com/)
- **Best Practice:** Always check the version dropdown in the top-left of the documentation page to ensure you are reading the docs for the release your instance is running (e.g., Washington DC).

## 🗺️ Learning Strategy
1. **Orient:** Watch an official overview video from the [@servicenow](https://www.youtube.com/@servicenow) channel.
2. **Study:** Complete the corresponding Learning Path on **Now Learning**.
3. **Reference:** Use the **Product Documentation** to verify specific technical constraints or table hierarchies.
4. **Build:** Implement the functionality in a PDI (Personal Developer Instance) to verify behavior.
